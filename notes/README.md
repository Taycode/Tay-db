# Notes

One file per chapter, in my own words. Name: `ddia-<chapter-title>.md` or `di-<number>-<title>.md`
(e.g. `ddia-storage-and-retrieval.md`, `di-07-log-structured-storage.md`).

Each file answers:

- **What problem does this solve?**
- **How does it work?** Draw it if that helps.
- **What does it cost?** What gets slower, bigger, or riskier?
- **Where does it show up in Tay-db?** Which step, which file.
- **What I still don't get.** Bring these to the walkthrough.
